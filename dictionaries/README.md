# Словари подсказок слов / Word-completion dictionaries

Файлы `<язык>.dict.gz`: сжатый gzip список `слово<TAB>частота` (частота — условный номер 1–255, больше = чаще).
Языки: de, fr, es, it, pt, pl, nl, cs, tr, ro, bg, sv, hu, el.

Источник: wordfreq 3.1.1 (Robyn Speer et al., https://github.com/rspeer/wordfreq). Взяты самые частые слова языка
(только буквы, 2–24 символа, не больше 60 000). Лицензия данных: **CC BY-SA 4.0**
(https://creativecommons.org/licenses/by-sa/4.0/) — с указанием источника и на тех же условиях.

Derived from wordfreq 3.1.1 (CC BY-SA 4.0): the most frequent words of each language (letters only, 2-24 chars, at most 60,000).
